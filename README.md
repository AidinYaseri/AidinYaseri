**Swift | SwiftUI | Core Location | Core Motion | SwiftData**

An iOS application designed to measure and analyze automotive performance using an iPhone's onboard sensors.

- Records acceleration times and distance runs
- Measures G-forces and live telemetry
- Visualizes performance through graphs and maps
- Stores run history and enables performance comparisons
